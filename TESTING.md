# Testing status

What has actually been played, watched or listened to, and what has only been checked in
the files. If a row says something has never been seen or heard, that is not modesty, it
means nobody has done it.

If you find something this page says is untested, [issue #1](../../issues/1) is the place.
Don't check whether it's already known first. A duplicate costs me nothing and a report
somebody talked themselves out of costs me a defect.

[DETAILS.md](DETAILS.md) opens with a list of known problems sorted by what they look like
on screen, which is the page to check if you want to know whether something you're seeing
is already on my list.
